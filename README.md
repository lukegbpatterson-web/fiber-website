# bayzl tripletest

A fresh, standalone workspace for designing a new website — intentionally
separate from the existing bayzl landing page.

- **Not related to** the `fiber-website` repo (basilseedfiber.com). That
  project's current state is preserved permanently on GitHub at the tag
  [`v1-bayzl-landing`](https://github.com/lukegbpatterson-web/fiber-website/tree/v1-bayzl-landing),
  independent of any future changes there.
- This folder has its own git history, starting from nothing, so work here
  can't overwrite or conflict with the existing site.
- No GitHub remote is connected yet. Create an empty repo on GitHub when
  ready and connect it the same way the other project was: `git remote add
  origin <url>`, then `git push -u origin main`.
